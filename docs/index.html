5 đặc tính NIST qua thao tác đã làm

  1. Tự phục vụ theo yêu cầu: tôi tự bấm Create codespace trên GitHub và có một máy ảo chạy được sau khoảng 4 phút, không cần ai cấp phát.
  2. Truy cập mạng rộng: tôi đổi cổng 3000 sang Public và mở API bằng điện thoại qua địa chỉ app.github.dev, rồi đổi lại Private.
  3. Gộp tài nguyên: API báo máy có 2 CPU và 7,8 GB RAM, tên máy (host) là codespaces-d23349, chạy trên hạ tầng dùng chung của GitHub (nhân Linux azure).
  4. Co giãn nhanh: tôi xóa codespace cũ và tạo codespace mới trong vài phút; khi cần máy mạnh hơn có thể chọn loại máy lớn hơn mà không phải mua phần cứng.
  5. Dịch vụ đo lường được: trang Billing, mục Usage, hiển thị Codespaces storage 0,03 GB-tháng, tổng phát sinh dưới 0,01 USD và số tiền phải trả là 0 USD nhờ hạn mức miễn phí.
